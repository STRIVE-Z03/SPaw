# 伴学爪交付汇报

2026-11-19，本地隔离环境。验收教材为人教版四年级数学下册。

## Agent 与学习

| 能力 | 交付结果 |
| --- | --- |
| 首页诊断与专项练习 | 合并竞技场和小爪练习的有效批改。按原题去重，采纳最新批改。智能组题和组卷只抽取竞技场可核对的题。掌握情况提高时，题量和难度随之提升。 |
| 学习分析 | 首次满 10 道实判题，显示知识图、答对圆环、薄弱点分布和语数英三角图。点知识点可查作答明细。语文、英语暂无样本时标为无记录。 |
| 教材与练习册整理 | 现有教材第 9 至 10 页扫描识别出 7 个待核对题块。练习册整理 41 题，其中 20 道已对照原题复核。管理员可预览 PDF，下载 Markdown、图片和索引。 |
| 知识点学习 | 六个知识点有离线讲解、图示例题、关联知识点和真实教材页链接。 |
| 教材答疑 | 先从已选教材检索。明确找教材出处且结果不足时，模型可调用一次 `search_textbook`，最多传 4 个知识点。服务端校验教材权限并组装页链接。讲解流式输出，可查看多个教材页。 |
| 做题辅助 | 根据当前作答和草稿给提示。提交后按实判结果逐步解释。问爪爪胶囊点开后居中悬浮，点 × 收回。 |
| 公开资料 | 页面操作触发 `search_public_sources`。Tavily 仅收到知识点检索词，链接经过域名筛选，每名学生滚动 24 小时最多 10 次。 |

儿童讲解规则要求短句、熟悉的词和具体例子，引用限于服务端提供的可读教材页。 [教学 Agent](../app/backend/agent/tutor.py) · [工具实现](../app/backend/agent/teaching_tools.py) · [儿童讲解规则](../app/backend/agent/skills/child-tutor/SKILL.md)

## 数据库

本地 SQLite 有 **44 张应用表**，以下为交付涉及的核心表。

| 模块 | 核心表 | 存储规则 |
| --- | --- | --- |
| 专项练习 | `practice_sets`、`practice_items`、`practice_attempts` | 学生与请求编号的组合唯一。同一题的首次提交生效，重交同一答案返回原判题结果。记录来源、组题方式及可选用时。 |
| 答疑与流式恢复 | `study_sessions`、`study_messages`、`study_jobs`、`study_images` | 会话用整数 `user_id` 关联账号。消息逐条保存，JSON 存教材引用等扩展数据。每个会话最多一个活跃任务。 |
| 检索与迁移 | `learning_source_requests`、`learning_migrations` | 按学生记录公开检索额度，用版本号记录结构迁移。 |
| 账号与通知 | `users`、`family_links`、`email_codes`、`notifications`、`notification_reads` | 同一邮箱可对应多个用户名。通知已读按账号和通知组合键存储，删除通知时级联清理。 |

SQLite 使用 WAL 和外键。题组创建、首次答题、验证码消费及任务结算使用短事务。模型请求和发信在事务外执行。面试可结合这三处说明幂等、事务边界和工具权限。 [字段与索引明细](database-and-tools.md)
