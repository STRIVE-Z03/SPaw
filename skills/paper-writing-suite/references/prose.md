# 通用表达与修订

1. 按用户目标和读者定位问题，指出具体原因，如空泛评价、缺少行动对象、同义重复或信息顺序不合读者需要。
2. 抽取段落功能和须保留的事实。写明主语、动作、比较或发现，删多余开场、重复弱化和没有信息的总结。最小修改先动造成问题的字词和句法，其余已经通顺的词语和指定不改的字句照留。合格原句可以保持原样。
3. 合并或删弱化前确认是否承担限定作用。对影响结论的范围使用具体表述，如“在室温台架试验中”。保留有据的谨慎措辞及方法段中自然的被动语态。
4. 按文体组织内容。通知优先动作和截止时间，邮件按读者需要写明下一步，论文优先主张、证据和范围。有作者样稿时匹配已有术语与语调。

成排连接词、句长雷同或固定句式用作回读线索。以信息是否可用、语义是否准确为准。用户只要成稿时直接交付成稿。
