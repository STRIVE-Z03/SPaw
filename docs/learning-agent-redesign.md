# 智能小爪陪你学改造方案

当前首页的「今天学什么」读取 `/api/learning/dashboard`，展示近期错题判断和专项推荐。首批单知识点题组、教材链接和儿童讲解可复用。交付库有 44 张表，本方案的目标是 22 张业务表。 [现有首页模块](../app/frontend/learning/personal-learning.js) · [当前交付与验证范围](delivery-report.md)

## 首页与分析报告

把「智能小爪陪你学」放在学生首页问候下方，取代「今天学什么」卡。首屏只给一条有证据的建议和两个按钮。例：**小数加法做了 5 题，错了 3 题。先练小数点对齐。**「练 5 道」直接组题，「看分析」打开报告。新学生先做入门题，样本不足时显示已记录的题数。 [首页入口](../app/frontend/shell/app.js)

报告默认近 30 天，可切换近 7 天。每张图配文字数据，点图可查看对应记录。

| 图表 | 指标和交互 |
| --- | --- |
| 圆环图 | 已批改题的答对与答错数，中心显示正确率。待批改单列。 |
| 饼图 | 错题按主知识点分布。点小数切到小数错题，保留总错题数。 |
| 三科三角图 | 语文、数学、英语各一轴，用同一口径的实判正确率和样本数。每科至少 5 道才绘制该轴。数据不足显示「题目还不够」，三科齐备才闭合三角。 |
| 薄弱点列表 | 显示错题数、常见错误线索和有记录的中位答题用时，提供错题、教材和专项练习入口。 |

## Agent 怎么判断和组题

1. **汇总证据。** 复用现有作答、章节批改和学习事件。只按实判作答计算正确率。新作答增加可空的 `active_ms`，统计题目在前台的有效作答时间，切后台暂停并在服务端校验范围。旧记录缺用时就留空。学生提问和对话按学科、知识点统计，用作反复卡住的线索。 [诊断服务](../app/backend/learning/service.py) · [学习统计](../app/backend/learning/learning_insights.py)
2. **解释证据。** 后端计算正确率、错题和用时。沿用至少 5 道、错至少 2 道且正确率低于 70% 的初始薄弱判定。Agent 读取已授权的汇总与证据编号，生成简短解释、建议和教材引用。后台校验证据与题目归属，首页读取上次结果，报告可刷新。大模型不可用时，按同一统计结果生成简短建议。 [教材工具](../app/backend/agent/teaching_tools.py)
3. **安排练习。** 首批按「3 道薄弱点 + 1 道前置知识 + 1 道复习题」组题，条件不足时优先选可核对的题。Agent 推荐知识点和顺序，服务端固定题组、验算及记录结果。同一题组请求可安全重试，练完刷新报告证据。 [题组存储](../app/backend/storage/learning.py)

首页沿用 `/api/learning/dashboard`，报告新增查询和更新入口。首页不等模型生成，直接读取已有建议。 [接口入口](../app/backend/http/learning.py)

## 44 张表缩到 22 张

按业务合并重复表，保留稳定的主键、外键和幂等键。配置、小段报告结果可以用 JSON。作答和消息继续逐条存储。

| 模块 | 现有 → 目标 | 目标表与合并方向 |
| --- | --- | --- |
| 账号、验证与通知 | 10 → 7 | `users`、`sessions`、`family_links`、`auth_requests`、`rate_limits`、`notifications`、`notification_reads`。图片验证码、邮箱验证码和人工重置请求归入 `auth_requests`，按用途约束摘要、有效期、状态。登录和会员操作限流归入 `rate_limits`。 |
| 题目、练习与学习事件 | 16 → 6 | `questions`、`practice_sets`、`practice_items`、`attempts`、`student_state`、`learning_events`。统一题库与当前题审、旧题组与生成请求、专项与章节作答。草稿、续做、题目浏览、跳题批次和设置按学生与对象分行。学习事件保留阅读等独立事实，与作答重复的事件只计一次。 |
| 对话与报告 | 4 → 4 | `study_sessions`、`study_messages`、`study_jobs`、`study_images`。报告复用 `study_jobs`，用学生、时间窗和数据版本去重，保留指标快照及摘要。 |
| 配置、会员与审计 | 14 → 5 | `memberships`、`membership_codes`、`quota_ledger`、`app_settings`、`audit_log`。公开检索、听写及会员用量归同一额度流水。配置按命名空间存放，题审和目录变更留审计，迁移版本用数据库版本号。 |

优先核对三组迁移。`practice_attempts`、`arena_attempts`、`question_checks` 合入 `attempts`。`practice_sets`、`generated_sets`、`generated_requests` 合入新版 `practice_sets`。`membership_usage`、`membership_dictation_keys`、`learning_source_requests` 合入 `quota_ledger`。

作答按学生与时间建索引，待批改的正确性字段留空。题组引用题目版本。迁移保留旧题版本、跳题批次引用、历史对话及额度状态。每组先在数据副本回填并比对，再切换应用读写。保留原库备份和明确的回退点。 [当前字段与索引](database-and-tools.md)

## 实施工单与验收

| 顺序 | 工单 | 验收 |
| --- | --- | --- |
| 1 | 首页主卡、数学报告、作答用时 | 5 道小数题错 3 道时，首页推荐小数。点报告可看到 2 对 3 错，图表与明细一致。切后台暂停计时，旧作答用时留空。 |
| 2 | Agent 建议、复合题组、语英数据接入 | 点「练 5 道」得到可验算的题组。每条建议可追溯到本人记录或教材。语英有足够样本才画三角轴。家长只可查看已绑定学生。 |
| 3 | 数据库回填和切换 | 测试库恰好 22 张业务表。比对历史总题数、正确率、答疑顺序、会员额度和通知未读数。外键检查 0 项违例，重复提交结果一致，完成回退演练。 |
