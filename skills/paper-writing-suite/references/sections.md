# 论文章节写作

先用目标期刊或既有目录。综述、工程报告和理论论文可按领域调整。

| 章节 | 写作任务 | 合稿时核对 |
| --- | --- | --- |
| 摘要 | 用已核验的问题、方法、主要结果与限制压缩成稿 | 数值、对象和范围与最终正文一致 |
| 引言 | 写具体问题、已有工作、可证实的缺口和本文贡献 | 可核验引用和结果能支持贡献 |
| 方法 | 写设计、样本、排除条件、测量、比较口径和分析 | 复现信息，区分预注册与实际分析 |
| 结果 | 报告估计量、分母、比较方向与不确定性，保留重要负向结果 | 对照表图、数据版本、方法和各组 |
| 讨论 | 说明证据支持到哪里，保留相反结果、边界与有据的替代解释 | 区分机制推断和观测结果 |
| 结论 | 回答原问题，交代适用对象与条件 | 与摘要和结果的主张强度一致 |

综述核对来源与归因，区分相关、联合作用和因果证据。缺方法或结果时写已支持的部分并标出待补项。全文起草先核实正文证据，再定稿摘要与结论。
