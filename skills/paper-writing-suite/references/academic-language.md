# 术语与论文语言

## 核对所指对象，再确定写法

先看术语在本稿指什么。具名方法、基准、数据集、模型、指标、标准和公式，按对应版本的原论文、正式规范或作者官方文档核对全称、大小写、缩写和定义。领域通用术语可参照同场次论文或领域规范。核对范围与定义比字面相似更重要。论文自定义术语应沿用作者定义。独立且有必要命名的概念可明确定义，并在后文保持一致。缺少可核对来源时，用稳定、直接的描述，暂不扩造英文全称或缩写。

草稿已有括号简称时，也要核对它是不是正式名称或后文会用的作者自定义。两者都不是时，删去简称，保留操作和对象。命名样式冲突时，依目标论文指定写法；正式名称只在标题或字体样式全大写时，不据此改正文拼写。例：从行为策略记录估计目标策略的期望回报，可写 off-policy evaluation，无需给本稿估计器新加简称。

例如，只有在外部检索结果用于支持生成时才按任务用 retrieval-augmented generation (RAG)。retrieval relevance、answer correctness 和 citation support 要按各自的评测对象区分。risk–coverage 中的 coverage 是接受预测的比例。被检索段落不足以支持答案，可写 “the retrieved passages do not support an answer”。按策略跳过回答可写 “the system abstains”，与问题本身是否可回答分别表述。无参考的题材依本稿定义，别把例子当术语表强行套用。

校对拼写、全称或简称时，可查来源后只改术语。纯润色、翻译或只规定标准命名时，沿用原稿的引文范围，查到的额外来源留作校对依据。任务要求补引文时，核实出处并把引文放在所支持的定义或已有工作之后。当前研究的实现细节单独写，避免引文看起来是在为本稿的实现作证。

## 论文正文用陈述句和具体动词

- 开头直接写研究对象、可观察现象或已有方法的具体不足。正文里的互动式设问、反问和自问自答改成陈述句。正式研究问题条目、原文标题、受试问卷与测试题按原格式保留。
- 拆开连续的名词修饰和为装饰加引号或破折号的临时词组。用动作写机制：如果模块为每个段落判断其能否支持回答，就用 “scores each passage for whether it supports an answer” 或写明评分量。evidence-aware 等常见构词只有在含义明确且有稳定指代时保留。区分正常连字符（如 retrieval-augmented）、关系连接号（如 risk–coverage）和用来插话的长破折号。保留官方名称和必要的数学符号。
- 方法交代谁用什么数据做什么，训练与测试各写清输入、判断对象和用途。参考答案参与奖励计算时，可以直写 “We use the reference answer to compute the reward during training.” 若测试输入范围已知，紧接着交代实际输入。只有文中定义了轨迹和评分量时，才用这些术语承载方法信息。
- 删除没有新增内容的“这一收益仍需通过实验验证”和同类收尾。已有实验就给测过的量与适用条件。未测的量若影响解读，直接说清未测什么。方案或假设应给比较对象、指标和条件，保持计划时态，避免把预期结果写成已有发现。
- 中文用操作或观察作句子骨架。范围限定尽量贴着主张，例如“本文只根据检索到的段落判断能否作答”，可从这句直接看出判定范围。材料若另给未检索范围及一项明确的未做检查，保留该边界。

## 英文逐句校对

1. 先找有限动词和真实主语。检查主谓一致、冠词和名词单复数、时态、代词指代、并列结构、比较双方和单位。
2. 再看搭配和修饰范围。比较结果时让同类量比较，避免关系从句或句尾分词接错对象。方法与结果可用清楚的主动或被动语态。已完成的实验与拟做的计划保持时态一致，无需机械把所有句子改成同一时态。
3. 连读相邻句。保留承载比较或适用条件的词，删宣传词、叠加弱化、助手自述和同义收尾。最后对照材料核对对象、范围、数值、结论强度和交付语言。没有新增含义的语言修整不应引入新名词。

## 逐句修订与遗漏复核

先列出每句必须传递的内容，包括实体、操作、数字和单位、比较参照、否定、条件、统计口径和证据归属。可以重组句子，合并或拆分后逐项追到对应成稿。取舍由章节用途和材料决定。原文保留“未比较”“未检验”或指标全称且会影响结论解读时，成稿保留具体量和范围。

逐一回查新加的范围词与对象。only、each、“仅”“各自”等词须有原文依据。引用证据以集合判定时，保留原来的集合，确认来源是否逐条绑定后再写 for each claim。将生成对象写成“回答”或“摘要”前，先确认素材限定了体裁。abstain 通常按“不作答”处理，材料明确会稍后作答才用“暂缓作答”。

逐句按三遍修。第一遍核对术语和事实。第二遍只处理句法、搭配、节奏及语域。第三遍拿成稿回对原文，找漏翻、复述、隐含的归因或新增名称。逐句交付时，对每句附原文定位、改后正文和修改理由。用户只要成稿时，前述核对留在校读过程中。

英译中按中文语序表达，保留必要的正式英文专名和缩写。中译英优先用目标论文或同领域的句式，避免按中文字序逐词回译。独立回译可以帮助发现否定、对象或限定被译掉。复核以原文为准，回译的字面相似度只作排查线索。

翻译时逐项核对操作动词的主语和宾语。区分介绍已有基线和提出新方法、复现方法和复现结果、未采用和取消。原句说明同一个工具服务于两个步骤时，译文用清楚的并列写出两个用途。候选资格、选择决策和实际执行分别表述。“可以考虑处理”保留待决状态，也比“成为候选处理对象”顺畅。缺少上下文时沿用原指代和抽象层次，避免把 worker 自行写成进程，或把 gold passage 等同于答案原句。在检索语境中，paraphrase 通常指同义改写或改述。先让读者认出研究对象。压在名词前的多层限定可移到下一句，逐一写清关系。删掉“这样一类问题，即……的问题”之类复述。

## 生硬表达的返修

- 先圈出中心名词。若它前面叠着来源、主题、条件或动作，将其中一项改成谓语，先让读者认出对象。比较多个对象时先点明比较量，用“与……相比”交代参照，再写差异，避免两端复述同一组词。逐个检查谁执行动词。原文的所属关系可写成“为该请求生成的词元”，让请求保持为处理对象。动作主体未知时用无施事句或自然被动。短定语能明确指代时可保留。拆句后逐句说出新增信息，删去只换词复述的过渡或结语。
- 逐句念出主谓和动宾组合。在“用 A 对 B 进行 C”中，若 C 是明确的动作，把它用作谓语，例如“用问答对联合微调两个模型”。人员临时分工写清每项任务有几人负责、各做什么。英文 generator、validator 等若所指会影响译文，先回查原论文首次定义或目标句前后一段，包括招募与分工说明。材料确认是人时用“名、人”计数并写具体动作，确认是程序时保留组件名。上下文无法核实时保留角色和数量，避免补写实现。解释临时术语的用法，例如用“作为提示输入的问题”明确问题的用途。相邻的同字或近义词只在造成误读、停顿或复述时调整。英文也先校动词及其宾语，再看介词或从句附着到哪里。
- 清稿后把时间、否定、条件和比较基准对回各自的谓语。区分“随后某一步可执行”和“紧接下一步执行”，以及“未找到”“不存在”和“检索未返回”。先列出原文明示的重复次数、任务划分单位、操作方式和文章类型，例如高亮与一般标出、立场论文与实证研究。成稿省去一项前，确认下文明确补足，或者用户授权概括。对一项工具的多个用途逐个点名。材料同时交代如何判定、按什么单位计数和怎么算比例时，逐项保留；用最终比例替代计数动作会少一层方法信息。样本范围只写一次，推论边界紧随其后。
- 先辨认引号里的词是不是数据、代码或标注输出的固定值。固定值和要求逐字保留的文字照录，可在句中解释其含义。普通术语按目标语言表达。引用中的排版变化要能分辨实际符号、可复制标签和书刊字形。

## 交付前对照改动

- 优先保留已经准确且顺畅的句子。材料只说变量纳入模型、条目接受标注或系统有资格继续处理时，沿用这一层描述。预测变量、标注落在何处、选取间隔等细节只有在来源给出时才写进正文。
- 回读比较句或比例句。相同的比较口径只说一次。要避免读错时可复用完整术语，例如明确写出“这两个经验量均可计算”。正文优先用短句报告分子和分母，如“我们报告获得支持的陈述占全部受评陈述的比例”。
- 结论、推论边界和检查范围分别核对。若原文说“不作答无法判断更广范围内是否可回答”，正文应保留这一边界。“实验未检查文档库以外”可另写一句。一个范围不能代替另一个范围。
- 遇到分工、执行门槛或逐项分配，写完后只看成稿重述三件事。谁对哪个对象做什么。何时取得资格，何时执行，哪种条件单独出现仍不够。每一个什么对应几项什么。逐条对回原文。原文说某个事件本身不启动操作时，在成稿保留针对该事件的否定，例如“恢复配额本身不会启动处理”。只写另一项必要条件会让这条限制依赖读者推断。逐项分配保持“每个”修饰的原对象，除非材料另给双向关系。固定标签逐字核对。最后核对要求的交付形式和句数。限两句时可把资格与不能立即执行并入同一句，另一句交代执行门槛。
- 结束前回看容易移动的限定词。写成“既有的知识库模式”时，“既有”修饰模式。在比较句里，“适用性较低”保留相对程度。按任务本身的要求判断哪些信息必需，原文给出指定解法时才写“标准解法”。
- 写例外前，从原文和可核实的上下文确定两件事。哪些对象属于例外，这些对象采用什么设置。若整个类别都是例外，先点明类别，再用一句或独立分句说明该类的设置，例如“评估采用零样本设置，少样本学习任务除外。这类任务的示例作为长上下文的一部分提供。”若原文只排除满足某条件的子集，保留该纳入条件。回读成稿，确认读者能根据类别和条件分出适用与例外的对象。原文无法确定覆盖范围时，沿用其范围。
- 词汇与语域单独审一次。证据准确仍要改掉拗口搭配、翻译式语序、口语套话、抽象名词串和无功能重复。选择能说明动作或关系的词，保留自然的学术被动、合法的限定、领域常用复合词和有作者定义的专名。

交稿前逐条做关系回读，只改有实际歧义或不顺的地方。

- 逐个还原动作主体和作用对象。甲调用乙来执行时，给执行分句写出乙。请求正在处理时，可用 “requests are still being processed”。描述同一批里的差异，先点明差异发生在哪个量上。表示适用程度下降，可写“适用性较低”，并保留“这些”等指向具体样本的词。
- 分开定义条件、动作方式与时间。若原文说按任务本身的要求判断哪些信息必需，可写“以求解任务本身所必需的信息作为条件变量”。只有原文指定某种算法或解题程序时才写“标准解法”。共用段首时间词之前，确认它适用于随后每个谓语；通用于各阶段的记录规则与仅在训练时发生的奖励计算可分两句写。
- 在转述两个后果时，分别读出造成的变化。若后一句必须跳过多层定语才能找到主语和动词，拆开后保留两种后果各自的对象和方向。拆句后如“这”“它”可指向多个对象，写清所指；所指清楚时继续用代词。
