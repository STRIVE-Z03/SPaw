# 智能推荐开发方案

当前组题根据作答规则运行。线上出题继续使用确定性筛选和可解释排序。下一阶段先改善候选覆盖与复习节奏，再用历史作答验证贝叶斯知识追踪（BKT）。本机当前可确认的人工复核样本集中于四年级数学，适合功能验收，数据量和覆盖面不足以估计各知识点的 BKT 参数或题目区分度。

## 开源实现

| 项目 | 读到的实现 | 在 SPaw 的用途 |
| --- | --- | --- |
| [pyBKT 一步预测](https://github.com/CAHLR/pyBKT/blob/master/source-py/pyBKT/fit/predict_onestep.py) | 用前向状态与学习、遗忘转移计算下次状态，以猜对率和失误率估计下一题的正确概率。 | 用离线拟合得到参数。线上按学生和知识点更新掌握概率，保留现有规则作为冷启动基线。 |
| [catsim 选题源码](https://douglasrizzo.com.br/catsim/_modules/catsim/selection.html) | MaxInfoSelector 按当前能力估计选择信息量高的题，分层选择方法将题目划入不同层。 | 先借鉴分层思想，用配额控制难度和题型，并限制题目曝光。题目区分度校准后，再评估最大信息量选题。 |
| [py-fsrs 调度器](https://github.com/open-spaced-repetition/py-fsrs/blob/main/fsrs/scheduler.py) | review_card 根据作答反馈更新复习状态和下次到期时间。 | 将到期复习放进独立候选池。先做简单间隔调度，待有按天复习记录后再比较 FSRS。 |



1. **先严格筛题。** 在 ArenaPracticeBank 层限制同年级。下一步按原题 ID 去重，为已复核且仍上架的题建立年级、科目、知识点和难度索引，降低每次组卷的扫描成本。保留计划题量和实际题量，零题时提示并结束。
2. **再做分层排序。** 起步定额为每组 5 题中的 3 道薄弱点、1 道到期复习、1 道新知识点诊断。池为空时在同年级内调配，待选题不足时保留已选题。按薄弱程度、最近错误和是否到期排序，限制同一题的连续曝光。给出简短的出题理由。
3. **验证 BKT 增益。** 从实判记录读取知识点 ID、题型、原题 ID、作答时间及正误。同一学习会话内的重复作答只用于练习反馈，避免重复增加掌握证据。模型按事件时间更新掌握概率。先按题型或科目分组估参数，样本不足时使用现有规则。用按时间切分的记录对比预测误差、薄弱点命中率和重复率，另用学生分组检验冷启动表现。用稍后首次作答的同知识点新题检查补练效果。
4. **用大模型辅助答疑和入库。** 答疑沿用专项模型和本地提示。入库在 OCR 后生成候选知识点、难度和常见错因，对照课程词表和原图复核。有疑义的题留在待核对队列。保留原题 ID、题目版本与复核结果，在线组题仅读取已审核数据。
